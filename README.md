# Clean Sweep updates

This repository hosts the signed update feed and complete ZIP updates for Sam Hurd's Clean Sweep plug-in for Lightroom Classic.

The initial installer is distributed by Sam through Patreon. Once installed, update notices work independently of Patreon membership and do not require a GitHub login. Download the latest preview from the [releases page](https://github.com/hurd300403/lightroom-removal-queue-releases/releases).

Each release includes the complete `.lrplugin` folder and its Mac companion. Finish or stop your batch, close the status window, replace the entire plug-in folder, and reload it in Lightroom's Plug-in Manager. Saved queue records stay in the catalog.

Automatic update checks can be disabled in the plug-in's Settings. Updates are never installed automatically. Checks run while Lightroom is open, including when the floating status window is closed.

The source repository is private. Distributed plug-in code remains covered by the license included with the download.

Clean Sweep was previously named Removal Queue. Existing installations keep the same update feed and saved batches. The `RemovalQueue.lrplugin` folder name stays unchanged for compatibility; Lightroom displays Clean Sweep.
