# Removal Queue updates

This repository hosts the signed update feed and future complete ZIP updates for Sam Hurd's Removal Queue plug-in for Lightroom Classic.

The initial installer is distributed by Sam through Patreon. Once installed, update notices work independently of Patreon membership and do not require a GitHub login. This repository currently announces no newer update.

Future releases will include the complete `.lrplugin` folder and its Mac companion. Finish or stop your batch, close the status window, replace the entire plug-in folder, and reload it in Lightroom's Plug-in Manager. Saved queue records stay in the catalog.

Automatic update checks can be disabled in the plug-in's Settings. Updates are never installed automatically. Checks run while Lightroom is open, including when the floating status window is closed.

The source repository is private. Distributed plug-in code remains covered by the license included with the download.
